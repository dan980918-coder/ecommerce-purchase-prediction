## 2. 시간 정보

- **공통 관측 기간:** 2022-06-23 ~ 2022-12-08 (5개 이벤트 테이블 모두 동일한 범위)
- **타임스탬프 형식:** `YYYY-MM-DD HH:MM:SS` 문자열(VARCHAR), 길이 19자로 고정. 밀리초·타임존 정보 없음
- **시간 해상도:** 초 단위. 다만 전체 행의 약 96.7%가 초 값이 5의 배수에 몰려 있음 (문제 요약 #9)
- **일별 이벤트 수 추이:** [`docs/figures/daily_event_counts.png`](figures/daily_event_counts.png) — 5개 테이블 모두 관측 기간 내내 **완만한 우상향 추세**와 **주간(요일) 패턴**(요일별 등락 반복)을 보임. 중간 수집 중단(0건 구간)은 없음. 마지막 날짜(2022-12-08)만 집계 버킷이 10분 미만이라 급락처럼 보임(문제 요약 #3). remove_from_cart는 2022-12-04에 단발성 급증(문제 요약 #8)
- **관측 기간의 의미:** 전체 기간이 좌우로 잘려 있어(censoring), 기간 시작 전부터 활동했을 고객과 기간 종료 후 행동했을 고객이 구분 없이 관측됨 (문제 요약 #4). 전반적 우상향 추세는 플랫폼 성장(또는 유저 기반 확대)을 반영할 수 있으나, 이 데이터만으로 원인을 특정할 수 없음

## 3. 키와 연결

### sku ↔ product_properties (양방향)

| 이벤트 테이블 | 이벤트 내 고유 sku 수 | → product_properties 매칭 | product_properties 고유 sku 수 | → 이벤트 테이블 매칭(역방향) | 행 단위 매칭률 |
|---|---|---|---|---|---|
| product_buy | 639,126 | 639,126 / 639,126 (100.00%) | 1,534,050 | 639,126 / 1,534,050 (41.66%) | 2,318,502 / 2,318,502 (100.00%) |
| add_to_cart | 1,444,160 | 1,444,160 / 1,444,160 (100.00%) | 1,534,050 | 1,444,160 / 1,534,050 (94.14%) | 7,541,117 / 7,541,117 (100.00%) |
| remove_from_cart | 824,536 | 824,536 / 824,536 (100.00%) | 1,534,050 | 824,536 / 1,534,050 (53.75%) | 2,688,894 / 2,688,894 (100.00%) |

- **정방향(이벤트→product_properties):** 세 이벤트 테이블 모두 100% 매칭 — 이벤트에 등장하는 sku는 전부 상품 카탈로그에 존재
- **역방향(product_properties→이벤트):** 카탈로그 전체 1,534,050개 sku 중 실제로 구매/장바구니담기/장바구니제거에 등장한 비율은 각각 41.66% / 94.14% / 53.75% — 카탈로그의 절반 이상은 구매로 이어지지 않은 sku

### page_visit.url

- url은 고유값 15,293,447개, 범위 0~16,491,808로 product_properties.sku(범위 0~1,623,140)와 ID 공간 자체가 다름. 두 컬럼을 잇는 공식 키나 문서상 매핑을 찾지 못함 → url은 상품과 직접 연결되지 않는 별도의 익명 식별자로 판단 (문제 요약 #11)

### search_query.query

- 원문 텍스트가 아니라 "[정수 16개]" 형태의 문자열(예: `[240 170 240 207 251 138 16 169 162 254 170 178 36 242 178 178]`) — 값 범위 0~255, 16차원 양자화 임베딩으로 추정. 원문 검색어는 데이터에 없음
- 전체 13,223,769건 중 고유값은 3,028,391개(22.90%)이며, 최빈값 1개가 2,817,157건(21.30%)을 차지 (문제 요약 #2)

### 구매 단위 (product_buy)

- **주문 ID 컬럼 없음** — client_id, timestamp, sku 세 컬럼만 존재
- (client_id, timestamp)를 "장바구니/주문" 묶음의 근사치로 사용하면: 전체 1,420,501개 묶음 중 1,188,002개(83.63%)는 서로 다른 sku 1종, 나머지 232,499개(16.37%)는 2종 이상
- 묶음 크기 분포(상위 일부, 전체는 [`product_buy_basket_size_dist.csv`](../data/processed/product_buy_basket_size_dist.csv)): 2종 132,982건, 3종 45,055건 … 최대 97종(1건), 20종 초과 묶음 828건
- 단, 이 근사치는 "완전히 동시각(동일 초)의 서로 다른 구매가 우연히 겹친 경우"와 "실제 한 주문"을 구분하지 못한다는 한계가 있음(위 동시 타임스탬프 표 참고)

### 이상값

- **미래 시각:** 0건 (모든 테이블)
- **관측 기간 밖 시각:** 정의상 min/max가 관측 범위이므로 0건
- **음수/비정상 값:** client_id, sku, url, category, price 모두 최솟값 0 또는 1 이상 — 음수 없음
- **결측 키:** 0건 (위 결측률 표 참고)

### product_properties: category, price 형태

- **category:** 고유값 6,912개, 범위 0~6,988 (익명화된 범주 ID, 일부 결번 존재)
- **price:** 고유값 **100개**, 범위 0~99, 평균 47.86 — 실제 통화 금액이 아니라 **0~99 사이로 구간화(binned)된 가격 지수**로 판단됨. 원가·화폐 단위 금액은 데이터에 없음
