# 이전 버전(v1) 보관

이 폴더는 2026년 8~9월에 진행한 첫 번째 분석(v1)을 그대로 보관한다.

- 범위: 고객 라이프사이클 세그먼트 분류, 이탈·구매 예측 모델, Streamlit 대시보드, LLM 기반 CRM 리포트 생성
- v2와 다른 점: 결과를 먼저 보고 그에 맞춰 가설과 세그먼트 정의를 정리했고, 완전 중복 행이나 검색어 기본값 같은 데이터 품질 문제를 결과 계산 전에 따로 점검하지 않은 채 다른 정제 기준을 적용했다
- 재분석한 이유: 위 두 가지가 결과의 신뢰도를 의심하게 해, 2026년 10월에 원데이터 점검부터 전 과정을 [`../../v2/`](../../v2/)에서 다시 설계했다. 비교는 루트 [`README.md`](../../README.md) 참고

이 폴더의 코드는 더 이상 유지보수하지 않는다. 루트의 `requirements.txt`는 v2 전용이라 이 코드를 그대로 실행할 수 없으며, 기록 보존 목적으로만 남긴다.
