# Phase 1 타당성 평가 보고서

8.1\~8.10 검증 결과를 근거로 각 분석의 가능 여부를 평가합니다. "가능"은 데이터
구조상 구현 가능함을 뜻할 뿐, 기준(이탈 정의·모델 종류 등)을 확정한 것은
아닙니다 — 그런 기준은 Phase 4 이후 사용자와 함께 정합니다.

## 종합 판단

- **가능**: 장바구니 이탈 분석, 14일 구매 비활성/구매성향 예측(단 우측 검열 처리 후), LLM CRM 리포트(수치 계산 없이 서술만 담당하는 방식)
- **제한적 가능**: 고객 단위 퍼널, 구매/코호트 리텐션, 카테고리 구매 예측 — 데이터 구조상 가능하지만 검열 문제·표본 급감을 반드시 함께 보고해야 함
- **불가능**: 상품 단위 퍼널, 가입 코호트, 실제 CLV, 캠페인 효과, 매출 개선, LLM 상품 카피 생성 — 이 항목들은 프로젝트 산출물에서 "할 수 있다"고 주장하지 않는다 (PROJECT_GUIDELINES.md 5번 "주장하면 안 되는 것"과 정합)
