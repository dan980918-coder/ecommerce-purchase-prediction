# Limitations — 프로젝트 한계 기록

이 문서는 분석·모델·대시보드 결과를 해석할 때 반드시 함께 고려해야 할
한계를 기록한다.

---

## 1. 데이터 최신성

**한계**: 사용하는 Synerise RecSys Challenge 2025 원본 데이터셋은 2022-06-23 \~
2022-12-08(약 6개월) 기간에 수집된 스냅샷이다. 프로젝트 기준일(2026-08-05) 기준으로
가장 최근 이벤트조차 약 3년 8개월 전 데이터이다.

**영향**
- 이 프로젝트는 **실시간/현재 고객 행동을 반영하지 않는다.** 모든 세그먼트, 라이프사이클
  상태, 모델 예측은 2022년 하반기 특정 시점의 행동 패턴을 반영할 뿐이다.
- "현재 이탈 위험 고객"과 같은 표현은 사용하지 않는다. 반드시 "2022년 6\~12월 관측
  데이터 기준"이라는 시점을 함께 명시한다.
- 이커머스 트렌드(모바일 전환, 프로모션 관행, 카테고리 구성 등)가 2022년 이후 변화했을
  가능성이 있어, 도출된 패턴이 현재 시점에도 동일하게 적용된다고 가정할 수 없다.

**대응**: 최신성 미충족을 이유로 Phase 1을 중단하지 않는 대신 모든 공개 산출물
(README, 대시보드, LLM 리포트)에 데이터 시점을 투명하게 명시하는 것을
정책으로 채택한다(PROJECT_GUIDELINES.md 10번 섹션(Phase 1 중단 조건)의 타임스탬프
관련 정책 참고).
표준 고지 문구:

> "본 프로젝트는 2022년 6\~12월 스냅샷 데이터를 사용하며, 이는 최신 고객 행동이 아닌
> 특정 시점의 이커머스 행동 패턴 분석임을 명시한다."

**체크리스트 (향후 Phase에서 확인)**
- [ ] README 상단에 데이터 시점 고지 포함 (Phase 10)
- [ ] Streamlit 대시보드 Overview 페이지에 데이터 시점 표기 (Phase 7)
- [ ] LLM CRM 리포트 출력에 데이터 시점 포함 (Phase 8\~9)
- [ ] 모델 카드(`reports/model_cards/`)에 학습 데이터 기간 명시 (Phase 5\~6)

## 2. 관측 기간이 고정된 6개월 창이라는 점에서 오는 구조적 제약

**한계**: 관측 기간이 6개월로 고정돼 있어(2022-06-23 시작 \~ 2022-12-08 종료), 다음
분석에 구조적 제약이 있다.
- 관측 시작 시점에 이미 활동 중이던 고객의 "진짜 첫 구매"를 알 수 없다 (첫 관측 구매 ≠ 첫 구매).
- 관측 종료 시점 이후 행동을 알 수 없어, 종료 시점 근처 고객의 장기 리텐션·이탈 여부를
  판단할 수 없다 (우측 검열, right-censoring).
- 6개월보다 긴 구매 주기를 가진 고객의 반복구매 여부를 과소평가할 수 있다.

**대응**: "신규 고객" 대신 "첫 관측 고객", "첫 구매" 대신 "첫 관측 구매", "생애가치"
대신 "관찰기간 내 행동가치" 표현을 PROJECT_GUIDELINES.md 8번 섹션 원칙대로 일관되게 사용한다.

**8.10 실측 결과 (2026-08-05, `reports/phase1_observation_period.md`)**:
- 고객별 관찰기간(첫\~마지막 행동) median **0일** — 66.33%(14,789,862명)가 하루만
  활동하고 다시 나타나지 않음.
- 좌측 검열(관측 시작 7일 이내 첫 등장) 후보: 전체 고객의 5.54%, 구매 고객
  기준 4.45%(40,428명) — 이들은 "첫 관측 구매"가 실제 첫 구매가 아닐 가능성이
  특히 높음.
- 우측 검열(관측 종료 14일 이내 첫 등장) 후보: 전체 고객의 8.17%, 구매 고객
  중 "관측 종료 14일 이내 마지막 구매"는 15.18%(138,041명) — 이들의 진짜
  이탈 여부는 데이터로 판단 불가능.
- Phase 5\~6에서 비활성/이탈 레이블을 만들 때 관측 종료 근처 고객(우측 검열
  대상)은 레이블이 사실상 "unknown"에 가까우므로, 학습셋에서 제외하거나
  별도 처리하는 방안을 그때 다시 검토한다.

## 3. category 컬럼의 신뢰도 — 익명 ID이며 상품명 기준 그룹핑과 낮은 일치도

**한계**: `stg_product_properties.category`는 실제 카테고리명이 아니라 익명화된
정수 ID다(Phase 1 8.5). 이 ID가 상품 간 실제 유사성을 얼마나 잘 반영하는지
검증하기 위해 상품명 임베딩(`name` 컬럼)을 MiniBatchKMeans로 클러스터링(k=50,
Kneedle 엘보우로 결정)한 뒤 기존 category 라벨과 일치도를 계산했다
(`scripts/analyze_category_reliability.py`, `_part2.py`).

**결과**: Normalized Mutual Information (NMI) **0.1258**, Adjusted Rand Index
(ARI) **0.0137** — 둘 다 0(무관)에 가깝고 1(완전 일치)과는 거리가 멀다. 즉
"category ID가 같다"는 것이 "상품명 임베딩 기준으로도 유사한 상품이다"를
거의 보장하지 못한다. 원인 후보로는 (a) category가 상품명이 포착하지 못하는
다른 기준(브랜드, 공급사 내부 분류 등)으로 매겨졌을 가능성, (b) 가장 큰
category(cat258, 전체의 3.39%)가 클러스터 순도 지표를 사이즈만으로 과대
왜곡했을 가능성이 있으나, 원본 데이터에 이를 확정할 근거 컬럼이 없어
원인은 미확정이다.

**영향**: 이 한계는 category를 사용하는 두 가지 산출물에 직접 영향을 준다.
- **`avg_category_repurchase_rate`(Model A/B feature, 2026-08-08 추가)**:
  이 feature는 "같은 category에 속한 상품은 재구매 패턴이 비슷하다"는
  전제 위에 있다. category가 명목상 그룹일 뿐 실제 상품 유사성과 약하게만
  연결된다면, 이 feature가 포착하는 신호는 "상품 유사성에 따른 재구매
  성향"이 아니라 "그 category ID 자체(운영/분류상 특성)에 따른 재구매
  성향"에 가까울 수 있다. Feature importance 상 기여는 확인됐지만(Model A
  9/13위), 그 기여의 인과적 해석("비슷한 상품을 사는 고객은 재구매를 잘
  한다")은 이 검증만으로는 뒷받침되지 않는다.
- **세그먼트 CRM 추천 액션의 "카테고리 기반" 문구**: `구매_직전_탐색형`·
  `첫_관측_구매_고관여형`·`반복구매_감소형`의 추천 액션에 "관심 카테고리
  기반 리마인더/추천"이 포함돼 있다(`reports/phase4_segment_profile.md`).
  category 그룹핑 자체의 상품 유사성이 약하다면, 이를 그대로 사용한
  카테고리 기반 추천이 고객이 실제로 관심 있어할 유사 상품과 어긋날
  위험이 있다.

**대응**: category를 "느슨한 운영 분류"로만 취급하고, "상품이 실제로
유사하다"는 강한 주장의 근거로 쓰지 않는다. 카테고리 기반 CRM 액션은
실험(A/B 테스트)으로 실제 반응률을 확인하기 전까지는 가설로만 제시한다.

## 4. price_bucket과 전환율의 비선형(굴곡형) 관계 — 참고용 관찰, 원인 미확정

**관찰**: `price_bucket`(0\~99 구간값, 실제 금액 아님 — Phase 1 8.5)별
장바구니 추가→구매 전환율을 계산한 결과(`reports/adhoc_price_bucket_conversion_full.csv`,
`scripts/generate_figures.py` fig04), 단순 선형 관계가 아니라 굴곡형(hump-shaped)
패턴을 보인다 — price_bucket 0(전환율 20.47%)에서 시작해 **price_bucket
59 부근에서 24.08%로 최고점**을 찍은 뒤, price_bucket 99(전환율 11.65%)까지
다시 하락한다. 양 극단(가장 싸거나 가장 비쌈)보다 중간\~중상위 구간의
전환율이 뚜렷이 높다.

**한계**: price_bucket이 실제 금액이 아니라 순위형 구간값이라 "가격이
얼마일 때 전환율이 가장 높다"는 금액 기준 해석은 불가능하고, 이 굴곡의
원인(예: 중간 가격대 상품 구성의 차이, 카테고리 분포 차이, 다른 교란
변수)을 확정할 근거 컬럼이 데이터에 없다. 단순 선형 상관계수만 봤다면
"가격이 낮을수록/높을수록 전환율이 높다"는 잘못된 단조적 결론으로
오도됐을 것이다.

**대응**: 이 관찰은 모델 feature나 세그먼트 기준으로는 사용하지 않는다
(원인이 불확정인 패턴을 예측에 바로 쓰는 것은 근거가 약함). 참고용
관찰로만 기록하고, 원인 규명이 필요하면 향후 카테고리별 price_bucket
분포 교차분석 등으로 후속 검증한다.
